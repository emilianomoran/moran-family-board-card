# Historical planning archive

GSD was retired on 2026-09-15. These files preserve the original research, phased plan,
foundation discussion, and verification history. They are not the current execution queue
or a source of mandatory reviewer-model or phase gates.

Start with [project documentation](../docs/README.md),
[decisions and discussion record](../docs/DECISIONS.md), and
[current status](../docs/STATUS.md). Record new product discussions there.

New agents should begin with [HANDOFF.md](../HANDOFF.md). The current
[backlog](../docs/BACKLOG.md) and [research map](../docs/research/README.md) separate completed
work and accepted choices from these dated proposals. Do not continue an old phase automatically.
