<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Home Assistant event/config data -> Lit templates | Titles, names, and metadata are untrusted browser-visible text. |
| Layout selector -> presentation branch | One config value controls whether new styles and markup are active. |
| Development harness/evidence -> public repository | Fixtures and screenshots can accidentally disclose household data or credentials. |
| Reviewed source -> minified HACS bundle | The deployed artifact must be generated from the reviewed implementation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-09 | Tampering / Elevation | Wall-shell rendering | mitigate | Render all text through normal Lit interpolation and prohibit `unsafeHTML`, `innerHTML`, executable URLs, and direct external fetches. |
| T-01-10 | Tampering | Layout/CSS isolation | mitigate | Gate on shared exact normalization and root every new selector/token beneath the unique wall root; verify legacy separately. |
| T-01-11 | Information Disclosure | Source examples, harness, documentation, execution evidence, screenshots, and generated bundle | mitigate | Replace household examples with Avery/Jordan/Casey/Household and `fixture_*` IDs; run the credential/private-identifier denylist across the explicit Phase 1 changed/evidence set including the completed summary, separately assert that Phase 1 implementation/source/test/harness files and `dist` contain no `/Volumes/config` reference, scan screenshot filenames/metadata, visually inspect screenshot content, and never open live HA for evidence. |
| T-01-12 | Denial of Service | Full-panel overflow | mitigate | Give overflow to the schedule region, retain bounded person-lane widths, and visually verify no whole-card clipping at 1920x1080. |
| T-01-13 | Tampering | Fixed-time seam | mitigate | Keep the provider as a non-dashboard instance dependency, clone returned dates, and default to the system clock; add no persisted test key. |
| T-01-14 | Tampering | Distribution artifact | mitigate | Build only through Rollup after source review and run all format/type/test/build gates before recording evidence. |
| T-01-SC | Tampering | npm package supply chain | accept | No package installation or dependency change is permitted in this plan; an unexpected manifest/lockfile diff blocks completion. |
</threat_model>
